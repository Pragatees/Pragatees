### 1. SmartReport AI — Multi-Agent Document Intelligence Platform

<img src="https://via.placeholder.com/900x300/0f0c29/ffffff?text=SmartReport+AI+—+Project+Banner" width="100%"/>

**Problem:** Analyzing large, domain-varied documents (financial reports, legal contracts, research papers) manually is slow and inconsistent, and generic RAG systems fail to adapt across domains or provide actionable follow-up.

**Solution:** A domain-agnostic multi-agent system that classifies the document's domain, extracts key insights, generates actionable recommendations, and supports memory-backed conversational Q&A grounded in the document content.

**Architecture**

```
Document Upload
      │
      ▼
┌─────────────────┐
│ Domain Detection │──▶ Identifies document type/domain
│      Agent       │
└────────┬─────────┘
         ▼
┌─────────────────┐
│ Insight Generation│──▶ Extracts key data points
│      Agent        │
└────────┬─────────┘
         ▼
┌─────────────────┐
│ Suggestion &      │──▶ Generates actionable next steps
│ Recommendation Agent│
└────────┬─────────┘
         ▼
┌─────────────────┐
│ Conversational RAG │──▶ Memory-backed document Q&A
│    Chat Agent       │    (FAISS vector retrieval)
└─────────────────┘
```

**Tech Stack:** FastAPI · React · FAISS · LangChain · LLaMA / GROQ / Gemini · Python

**AI Components:** Multi-agent orchestration, domain classification, RAG retrieval, conversational memory

**Key Features**
- Automatic domain classification — no manual document tagging required
- Multi-agent pipeline separating extraction, reasoning, and recommendation
- FAISS-backed semantic search for grounded, low-hallucination answers
- Memory-enabled chat for multi-turn document Q&A
- Async FastAPI backend with streaming responses
